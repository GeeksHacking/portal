# GeeksHackingPortal.WebApp

Frontend for the GeeksHacking Portal built with Nuxt. See Nuxt docs: https://nuxt.com/docs

## Setup

Install dependencies with your package manager of choice:

```bash
# pnpm (recommended)
pnpm install

# npm
npm install

# yarn
yarn install
```

## Development

Start dev server:

```bash
pnpm dev    # or `npm run dev` / `yarn dev`
```

Open http://localhost:3000 after the server starts.

## API client

The app uses `@geekshacking/portal-sdk`, generated by [kubb](https://kubb.dev/) from the API OpenAPI document. Kiota is not used.

Regenerate against the local API (`http://localhost:5227/openapi/v1.json` by default):

```bash
pnpm codegen
```

From the repo root, `mise run codegen` targets production and `mise run codegen-local` waits for the local API, then generates.

## Production

Build and preview:

```bash
pnpm build
pnpm preview
```

Refer to Nuxt deployment docs for hosting instructions.
